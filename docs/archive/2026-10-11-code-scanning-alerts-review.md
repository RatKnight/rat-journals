## Per-rule findings

### `rust/hard-coded-cryptographic-value` (44)

Every alert is generated by a test/bench fixture password or by a zero-initialised buffer. CodeQL does not honour `cfg(test)` gating for Rust, and the rule flags any literal that reaches a password or key parameter, even when the consumer is a throwaway file in a test.

#### C. Production code — 1 alert

- #462 `crates/mini-diarium-crypto/src/crypto/cipher.rs:37` — `let mut key = [0u8; KEY_SIZE];`

The array is a zero-filled buffer that the next line overwrites with `key.copy_from_slice(bytes)`. The key bytes come from the caller. No key is hard-coded. An optional cleanup would also silence the rule:

```rust
let key: [u8; KEY_SIZE] = bytes.try_into().ok()?;
```

Not applied: there is no functional or security need, and the alert is a false positive. Recorded here as an option only.
